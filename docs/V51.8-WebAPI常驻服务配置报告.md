## 三、公网访问说明（重要）

**当前限制：** WebAPI绑定在`127.0.0.1:8765`，飞书云端无法直接回调到本地。

**要让飞书卡片按钮真正生效，需要公网可访问的回调URL。两种方案：**

### 方案A：内网穿透（推荐，零成本）
```bash
# 安装cpolar或ngrok后：
cpolar http 8765
# 会得到一个公网URL，如 https://xxx.cpolar.top
# 飞书开放平台 → 事件订阅 → 请求地址填：
# https://xxx.cpolar.top/card-callback
```

### 方案B：云服务器部署
- 将webapi.py部署到云服务器
- 绑定0.0.0.0:8765
- 配置Nginx反向代理+HTTPS

### 方案C：使用GitHub Actions（已实现）
- 当前`webapi_on_demand.yml`已实现云端问答
- 卡片按钮回传暂不支持（GitHub Actions是触发式，非常驻）
