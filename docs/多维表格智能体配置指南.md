## 一、什么是多维表格智能体

多维表格智能体是飞书多维表格内置的AI助手，可以：
- 基于知识库进行智能问答
- 满足条件时自动执行任务
- 批量处理表格数据
- 自动生成内容

**优势：**
- 飞书原生托管，无需维护Python脚本
- 每月有免费使用额度
- 可视化配置，易于修改
- 与表格深度集成

## 三、具体实施步骤

### 3.1 第一步：错题解析迁移（最简单）

**目标：** 用多维表格AI字段捷径替代deepseek_assistants.py的错题解析功能

**操作步骤：**

1. **打开学习卡片表**
   - 进入多维表格：https://acn8z05ycj5w.feishu.cn/base/X8N1bvN3na99dFsyu0gcU8zTnHf
   - 选择"学习卡片表"（tblpLvxyYpDJgF92）

2. **新建字段**
   - 点击"+"新建字段
   - 字段标题：`AI解析_错题`
   - 字段类型：选择"探索字段捷径" → "智能体"

3. **配置智能体指令**
   ```
   请根据以下错题信息，生成JSON格式的解析：
   {
     "分析": "一句话核心概念澄清",
     "知识点": "分类标签",
     "正解": "简明正确思路",
     "规律": "底层规律"
   }
   
   错题内容：{{卡片问题正面}}
   学生答案：{{学生答案}}
   正确答案：{{标准答案}}
   ```

4. **测试并应用**
   - 点击"生成预览"测试效果
   - 满意后点击"应用全列"

**预期效果：**
- 新增错题时自动生成解析
- 无需调用DeepSeek API
- 使用飞书免费AI额度

### 3.2 第二步：洞察自动标签迁移

**目标：** 用AI字段捷径替代InsightArchiver的自动标签功能

**操作步骤：**

1. **打开洞察笔记表**
   - 选择"洞察笔记表"（tblaqKBl87V9C0q1）

2. **新建字段**
   - 字段标题：`自动标签`
   - 字段类型：AI字段捷径

3. **配置指令**
   ```
   请根据以下洞察内容，提取3-5个关键词标签：
   {{内容}}
   
   输出格式：标签1, 标签2, 标签3
   ```

4. **新建字段：自动分类**
   - 字段标题：`关联科目`
   - 字段类型：AI字段捷径
   - 指令：
   ```
   请判断以下洞察属于哪个学科/领域：
   {{内容}}
   
   可选分类：认知、考证、酒店工程、财商、人性、沟通、通用知识
   只输出分类名称。
   ```

### 3.3 第三步：学习周报自动生成

**目标：** 用多维表格智能体替代weekly_review.py

**操作步骤：**

1. **创建多维表格智能体**
   - 进入多维表格主页
   - 点击左侧"智能体" → "+新建智能体"
   - 名称：`学习周报生成器`

2. **配置智能体指令**
   ```
   你是一个学习周报生成助手。请根据以下数据生成本周学习周报：
   
   本周学习卡片数：{{本周新增卡片数}}
   掌握卡片数：{{本周掌握卡片数}}
   科目分布：{{科目分布}}
   
   请生成包含以下内容的周报：
   1. 本周学习总结
   2. 薄弱环节分析
   3. 下周学习计划
   ```

3. **配置触发条件**
   - 触发器：每周日晚上8点
   - 动作：生成周报 → 写入洞察笔记表 → 发送到飞书群

## 四、工作流AI Agent节点配置

### 4.1 适用场景

适合将以下Python脚本迁移到飞书原生工作流：
- 早报生成
- 晚报生成
- 定时提醒
- 数据汇总

### 4.2 早报工作流配置步骤

1. **进入多维表格工作流**
   - 打开任意多维表格
   - 点击左侧"工作流" → "+新建工作流"

2. **配置触发条件**
   - 触发器：定时触发
   - 时间：每天早上8:00

3. **添加AI Agent节点**
   - 节点类型：AI Agent
   - 配置指令：
   ```
   请生成今日早报，包含以下内容：
   1. 今日天气（西安）
   2. 今日待办任务列表
   3. 今日复习卡片数
   4. 昨日完成情况总结
   
   数据来源：
   - 任务列表：{{任务表数据}}
   - 复习卡片：{{学习卡片表数据}}
   ```

4. **添加发送消息节点**
   - 节点类型：发送飞书消息
   - 目标：总控群
   - 内容：{{AI Agent输出}}

## 七、风险与注意事项

### 7.1 风险

| 风险 | 影响 | 应对 |
|-----|------|------|
| 飞书AI额度用完 | 功能不可用 | 保留Python脚本作为fallback |
| 智能体配置错误 | 数据错误 | 先测试再全量应用 |
| 迁移过程数据丢失 | 历史数据 | 迁移前备份 |

### 7.2 注意事项

1. **渐进式迁移**：不要一次性全部迁移，先从简单功能开始
2. **保留fallback**：Python脚本暂时保留，作为备选方案
3. **充分测试**：每个功能迁移后先测试1-2周
4. **数据备份**：迁移前备份多维表格数据
