## 二、备份策略

### 2.1 备份频率
- **每日备份**：凌晨3:00（随每日维护任务执行）
- **保留策略**：7轮滚动备份
- **备份位置**：`backups/` 目录

### 2.2 备份脚本
- **脚本路径**：`scripts/backup_with_rotation.py`
- **执行方式**：自动随每日维护执行

### 2.3 备份内容
- 每张表导出为JSON文件
- 包含字段定义+所有记录
- 带时间戳命名备份目录

## 三、恢复流程

### 3.1 手动恢复
1. 找到需要恢复的备份目录
2. 读取JSON备份文件
3. 使用 `lark-cli base +record-batch-create` 恢复记录

### 3.2 恢复演练
- **频率**：每月1次
- **目的**：验证备份可用性
- **范围**：随机选1张表恢复到测试表

---

## 四、备份检查

### 4.1 每日检查
- 备份是否成功生成
- 备份文件大小是否正常
- 记录数是否合理

### 4.2 告警阈值
- 🔴 备份失败：立即告警
- 🟡 备份记录数明显减少：告警
- 🟡 连续3天备份失败：严重告警
