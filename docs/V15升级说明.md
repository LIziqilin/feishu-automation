## 二、系统进化机制（越用越懂我）

### 2.1 进化原理

**核心逻辑**：数据积累 → 模式识别 → 个性化适配 → 正反馈循环

```
你使用系统 → 产生数据 → 系统学习模式 → 优化推荐 → 你更愿意用 → 更多数据
```

### 2.2 四大学习维度

| 维度 | 学习什么 | 数据来源 |

| 学习行为模式 | 什么时候记忆力最好/哪类知识点掌握快 | 复习流水表 |

| 交互偏好模式 | 喜欢什么语气/多详细的解释 | 对话历史 |

### 2.3 用户画像表（新增）

## 三、知识框架深化

### 3.1 三层知识架构

#### 第一层：知识地图（MOC - Map of Content）
- 每个领域一个知识索引页
- 像目录一样导航，知道学了什么/没学什么
- 找到下一步学习方向

**示例 - 机电工程MOC**：
```
# 机电工程知识地图

## 一、给排水系统
- [ ] 水泵原理
- [ ] 管道设计
- [ ] 污水处理

## 二、空调系统
- [x] 冷水机组
- [ ] 冷却塔
- [ ] 风系统
```

#### 第二层：知识连接
- 手动双链：[[ ]] 语法
- 语义关联：smart-connections AI自动推荐
- 分类标签：按领域/类型分类

#### 第三层：知识网络
- Obsidian Graph View全局可视化
- 按领域着色
- 按掌握度着色（绿=已掌握/黄=学习中/红=未学）

### 3.2 四大知识功能

| 功能 | 说明 | 优先级 |
|---|---|---|
| 知识缺口分析 | 自动分析知识覆盖率，推荐下一步学习 | P1 |
| 知识关联推荐 | 学一个知识点时推荐相关知识点 | P1 |
| 费曼输出验证 | 用自己的话讲出来，系统打分 | P2 |
| 知识体系演进图 | 每月生成知识增长可视化 | P2 |

## 四、本地AI优化

### 4.1 模型选择策略（针对i5-8250U+16G内存）

| 场景 | 用什么 | 为什么 |
|---|---|---|
| Embedding（语义关联） | Ollama nomic-embed-text ✅ | 已在用，不占资源 |
| 简单问答/摘要 | Ollama qwen2.5:1.8b | 快，不依赖网络 |
| 复杂推理/写作 | 云端DeepSeek/通义千问 | 质量高，省本地资源 |
| RAG问答 | AnythingLLM + 云端模型 | 知识库检索+云端生成 |

**为什么不推荐7b模型**：
1. i5-8250U是4核低压U，推理速度慢
2. 16G内存还要跑Obsidian+AnythingLLM+飞书脚本
3. 无独立显存，全靠CPU推理
