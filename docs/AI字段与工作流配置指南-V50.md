## 一、洞察笔记表添加自动标签AI字段

### 1.1 配置目标

在洞察笔记表中添加一个AI字段，自动根据洞察内容提取关键词标签。

### 1.2 详细操作步骤

**步骤1：打开洞察笔记表**
1. 进入多维表格：https://acn8z05ycj5w.feishu.cn/base/X8N1bvN3na99dFsyu0gcU8zTnHf
2. 选择"洞察笔记表"

**步骤2：新建字段**
1. 点击表格最右侧的"+"号新建字段
2. 字段名称输入：`自动标签_AI`
3. 字段类型选择：点击"探索字段捷径"
4. 在AI类字段中选择："自定义AI自动填充"

**步骤3：配置AI指令**
在"请输入指令"框中输入以下内容：

```
请根据以下洞察内容，提取3-5个关键词标签，用逗号分隔。

洞察内容：{{内容}}

要求：
1. 标签要简洁，每个标签2-4个字
2. 优先提取核心概念和主题
3. 不要重复或相似的标签
4. 只输出标签，不要其他解释
```

**步骤4：引用字段**
1. 点击输入框旁边的"+"号
2. 选择"内容"字段（即洞察正文）
3. 确认引用正确

**步骤5：测试并应用**
1. 点击"生成预览"
2. 检查AI生成的标签是否合理
3. 满意后点击"应用全列"

**步骤6：验证效果**
- 查看历史洞察记录是否自动生成了标签
- 新增一条洞察，观察是否自动生成标签

## 二、任务到期提醒工作流配置

### 2.1 配置目标

当任务到期时，自动发送提醒到飞书群。

### 2.2 详细操作步骤

**步骤1：进入工作流配置**
1. 打开多维表格
2. 点击左侧导航栏的"工作流"
3. 点击"+新建工作流"
4. 名称输入：`任务到期提醒`

**步骤2：配置触发条件**
1. 触发器选择："定时触发"
2. 频率选择："每小时"
3. 开始时间：选择当前时间后1分钟
4. 确认触发设置

**步骤3：配置筛选条件**
1. 点击"添加条件"
2. 条件1：
   - 字段：状态
   - 条件：等于
   - 值：待办
3. 条件2：
   - 字段：截止日期
   - 条件：早于
   - 值：现在
4. 条件3：
   - 字段：截止日期
   - 条件：晚于
   - 值：1小时前
5. 确认三个条件为"且"关系

**步骤4：配置动作**
1. 点击"添加动作"
2. 动作类型选择："发送飞书消息"
3. 接收人选择：紫麒麟（或总控群）
4. 消息内容输入：

```
⏰ 任务到期提醒

📋 任务名称：{{任务名称}}
📅 截止日期：{{截止日期}}
⭐ 优先级：{{优先级}}
📂 类别：{{类别}}

请及时处理！
```

**步骤5：测试工作流**
1. 先创建一个测试任务：
   - 任务名称：测试到期提醒
   - 截止日期：设为1小时后
   - 状态：待办
2. 等待1小时（或调整触发频率为每分钟）
3. 验证是否收到提醒消息

**步骤6：启用工作流**
1. 测试通过后，点击"启用工作流"
2. 确认工作流状态为"已启用"

## 五、常见问题

### Q1: AI字段生成速度慢怎么办？
A: 飞书AI字段生成需要几秒到十几秒，首次全列生成可能需要更长时间。

### Q2: 工作流触发不及时怎么办？
A: 定时工作流最短可以设置为每分钟一次，但会消耗更多额度。建议日常使用每小时一次。

### Q3: 如何修改AI字段的指令？
A: 点击字段名 → 编辑字段 → 修改AI指令 → 重新应用。

### Q4: 工作流发送消息失败怎么办？
A: 检查接收人是否正确、是否有发送权限、多维表格是否有飞书消息发送权限。
