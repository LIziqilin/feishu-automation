## 四、任务到期提醒工作流配置指南

### 4.1 配置目标

当任务到期时，自动发送提醒到飞书群。

### 4.2 配置步骤

**步骤1：新建工作流**
1. 打开多维表格
2. 点击左侧"工作流" → "+新建工作流"
3. 名称：`任务到期提醒`

**步骤2：配置触发条件**
- 触发类型：定时触发
- 频率：每小时检查一次
- 开始时间：现在

**步骤3：配置筛选条件**
- 条件1：状态 = 待办
- 条件2：截止日期 <= 现在
- 条件3：截止日期 >= 现在-1小时

**步骤4：配置动作**
- 动作类型：发送飞书消息
- 接收人：紫麒麟（或总控群）
- 消息内容：
```
⏰ 任务到期提醒
任务名称：{{任务名称}}
截止日期：{{截止日期}}
优先级：{{优先级}}

请及时处理！
```

**步骤5：测试并启用**
1. 先创建一个测试任务，截止时间设为1小时后
2. 等待触发，验证消息是否发送
3. 测试通过后启用工作流
