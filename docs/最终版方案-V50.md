## 一、系统概述

本系统是一套基于飞书多维表格 + GitHub Actions + DeepSeek + Coze + AnythingLLM + 交互式卡片的个人 AI 效率系统，覆盖**学习管理、任务管理、知识管理、运维监控、云端问答、智能提醒**六大核心场景。

### 1.1 核心能力

| 模块 | 功能 | 入口 |
|------|------|------|
| 学习系统 | 间隔重复闪卡、错题解析、知识检索、学习周报 | 飞书总控群 |
| 任务系统 | 新建/完成/归档任务、批量新建、待办清单、智能提醒 | 飞书总控群 |
| 知识系统 | 洞察归档、知识检索、用户画像演化 | 飞书总控群 |
| 推送系统 | 早报/午报/晚报、系统体检、定时推送 | 自动推送 |
| 运维系统 | 健康自检、桥接巡检、备份、异地备份 | 自动运行 |
| 云端问答 | GitHub Actions 云端调用 DeepSeek 推群 | 手动触发 |
| webapi | 本机 HTTP API，外部调用 AI 问答 | localhost:8765 |
| **交互式卡片** | **任务卡片、提醒卡片、洞察卡片、告警卡片** | **飞书群卡片** |
| **智能提醒** | **自然语言创建提醒，到点自动推送** | **飞书总控群** |
| **飞书任务智能体** | **注册为飞书任务智能体，支持自然语言操作** | **飞书任务中心** |

## 四、V50 新增功能

### 4.1 智能提醒系统

**功能说明：**
用户在飞书群里发送自然语言提醒，系统自动解析时间并创建带截止时间的任务，到点自动推送提醒。

**支持的格式：**
- `提醒我明天下午3点开会`
- `提醒：明天下午3点开会`
- `提醒 1小时后复习`
- `提醒我1小时后复习`

**支持的时间表达式：**
- `X小时后` / `X分钟后`
- `明天上午/下午/晚上X点X分`
- `后天上午/下午/晚上X点X分`
- 默认：30分钟后

**工作流程：**
1. 用户发送"提醒XXX"
2. 系统解析时间表达式
3. 在任务总表创建带截止日期的任务（类别：提醒）
4. 到点后系统自动推送提醒消息到群里

**实现文件：** `task_insight_extension.py`

---

### 4.2 交互式消息卡片

**功能说明：**
将纯文本回复升级为带按钮的交互式卡片，用户点击按钮即可完成操作，无需输入文字指令。

**卡片类型：**

| 卡片类型 | 按钮 | 使用场景 |
|---------|------|---------|
| **任务卡片** | 完成任务、延迟1天、归档 | 任务创建后、到期提醒 |
| **提醒卡片** | 已完成、10分钟后再提醒 | 提醒到点推送 |
| **洞察卡片** | 转为待办、查看详情 | 洞察归档成功 |
| **告警卡片** | 立即处理、已知晓 | 系统健康告警 |

**技术规范：**
- 卡片JSON格式：飞书卡片V2组件
- 支持按钮回传交互
- 支持多种样式（primary/default/danger）

**实现文件：** `feishu_cards.py`

将"我的助手"机器人注册为飞书任务智能体，支持在飞书任务中心直接通过自然语言操作任务。
