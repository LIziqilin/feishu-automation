## 一、交互式卡片按钮回调（长连接方案）

### 1.1 方案演进

| 方案 | 状态 | 原因 |
|-----|------|------|
| Webhook + cpolar | ❌ 放弃 | cpolar免费版域名1天内变动，不稳定 |
| 公网云服务器 | ❌ 过重 | 个人系统无需额外服务器 |
| **飞书WebSocket长连接** | ✅ **最终方案** | 免费、稳定、无需公网URL |

### 1.2 工作原理

飞书开放平台支持"使用长连接接收事件"模式：
1. 本地通过`lark-cli event consume`主动连接飞书WebSocket
2. 用户在群里点击卡片按钮
3. 飞书通过长连接把事件推送到本地
4. `card_event_handler.py`解析事件并更新多维表格
5. **全程不需要公网URL、不需要内网穿透**

### 1.3 事件链路

```
用户点击卡片按钮
  → 飞书云端
  → WebSocket长连接推送
  → lark-cli event bus (PID 常驻)
  → card_event_handler.py
  → lark-cli base +record-upsert 更新任务状态
  → 群内推送完成通知
```

## 二、弹窗消除（pythonw.exe）

### 2.1 问题

电脑频繁弹出`python.exe`和`cmd.exe`黑色控制台窗口。

### 2.2 根因

计划任务直接调用`python.exe`运行脚本时，Windows会弹出控制台窗口。

### 2.3 修复方案

| 任务类型 | 修复方式 |
|---------|---------|
| 常驻服务（WebAPI、CardEventHandler） | 改用`pythonw.exe`（无窗口Python） |
| 定时任务（心跳、早报、轮询等） | 通过`run_hidden.vbs`包裹（窗口模式0=隐藏） |

### 2.4 修改的计划任务

| 计划任务名 | 修改前 | 修改后 |
|-----------|-------|-------|
| FeishuAssistant-WebAPI | python.exe | pythonw.exe |
| FeishuAssistant-CardEventHandler | python.exe | pythonw.exe |
| FeishuAssistant-Heartbeat-Morning | python.exe | run_hidden.vbs + python.exe |
| FeishuAssistant-Heartbeat-Noon | python.exe | run_hidden.vbs + python.exe |
| FeishuAssistant-Heartbeat-Night | python.exe | run_hidden.vbs + python.exe |
