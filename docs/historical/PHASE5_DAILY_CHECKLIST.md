## 三、验收标准

### 3.1 通过标准（全部满足）

1. **3个任务计划连续3天正常运行**，LastTaskResult全部为0
2. **poll每5分钟运行一次**，无连续失败（连续失败≥3次视为P0）
3. **早报每天07:30自动推送**，3天全部成功
4. **维护任务每天03:00自动执行**，derive重算+备份全部成功
5. **流水表每天有新增记录**（至少1条答题记录）
6. **无P0故障**（系统崩溃、数据丢失、任务计划全部失败）
7. **无P1故障累积**（告警日志无错误/严重告警）
8. **真实交互验证全部通过**（答题/解析失败/闲聊/早报）

### 3.2 失败标准（任一满足）

1. 任何任务计划连续失败≥3次
2. poll连续1小时未运行
3. 早报连续2天未推送
4. 数据丢失（流水表记录数减少）
5. P0故障未在24小时内修复

## 四、问题处理流程

1. **发现问题** → 立即记录问题时间、现象、影响范围
2. **P0问题**（系统崩溃/数据丢失/任务全部失败）→ 立即停止验证，启动回滚SOP，24小时内修复
3. **P1问题**（单次失败/功能异常）→ 记录问题，当天修复，不影响验证继续
4. **P2问题**（体验问题/优化建议）→ 记录问题，验证结束后统一处理
5. **每天21:00日总结** → 记录当天运行情况、问题、修复情况
