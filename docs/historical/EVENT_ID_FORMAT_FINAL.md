# event_id 格式正式变更定稿

**变更日期**: 2026-09-11
**变更类型**: 正式架构变更（替代V16定稿的event_id=message_id）
**变更原因**: 实际施工中发现message_id在按钮触发/历史迁移/批量导入场景下不可用，统一为`卡片ID|结果|时间戳`格式更通用
**审批**: 用户正式确认（2026-09-11）

---

## 一、定稿格式

### event_id = `卡片ID|结果|毫秒时间戳`

**示例**:
```
recvtLY8poT8zw|会|1757568000000
recvtLY8poQDLb|不会|1757568060000
recvtNKGDut2Ac|模糊|1757568120000
```

**字段说明**:
| 字段 | 说明 | 示例 |
|------|------|------|
| 卡片ID | 学习卡表的record_id | recvtLY8poT8zw |
| 结果 | 答题结果（会/不会/模糊/INIT/REVOKE/ADMIN_OVERRIDE） | 会 |
| 毫秒时间戳 | 事件发生时间的Unix毫秒时间戳 | 1757568000000 |

**分隔符**: `|`（竖线）

---

## 二、与原定稿的差异

### 原V16定稿: event_id = message_id

**问题**:
1. 按钮触发场景无message_id（用户在表内点击按钮，不经过群消息）
2. 历史迁移数据无message_id（从旧系统导入的记录）
3. 批量导入无message_id（Seed初始化的23条记录）
4. INIT事件无message_id（系统初始化，非用户触发）

### 新定稿: event_id = `卡片ID|结果|时间戳`

**优势**:
1. 全场景通用（群指令/按钮/历史迁移/批量导入/INIT）
2. 自带业务语义（从event_id可直接看出是哪张卡、什么结果、什么时间）
3. 天然幂等（同一张卡、同一结果、同一毫秒不可能重复）
4. 不依赖外部系统（不需要先获取message_id才能写流水）

---

## 三、幂等性保证

### 唯一性约束
- 流水表event_id字段设为UNIQUE（业务唯一键）
- 同一卡片同一结果同一毫秒时间戳 = 同一事件，重复写入被拒绝

### 幂等验证
- 实测62条流水（V21返工后），event_id全部唯一，0重复 ✅
- 三次rebuild-all结果完全一致，derive确定性成立 ✅
- 撤回功能端到端验证通过（superseded/REVOKE/revoke_of全部正常）✅

## 四、各场景event_id生成规则

| 场景 | event_id生成方式 | 示例 |
|------|------------------|------|
| 群指令答题 | 卡片ID + 结果 + 消息时间戳 | recvtLY8poT8zw\|会\|1757568000000 |
| 按钮答题 | 卡片ID + 结果 + 点击时间戳 | recvtLY8poT8zw\|不会\|1757568060000 |
| INIT初始化 | 卡片ID + INIT + 创建时间戳 | recvtLY8poT8zw\|INIT\|1757500000000 |
| REVOKE撤回 | 卡片ID + REVOKE + 撤回时间戳 | recvtLY8poT8zw\|REVOKE\|1757568120000 |
| ADMIN_OVERRIDE | 卡片ID + ADMIN_OVERRIDE + 操作时间戳 | recvtLY8poT8zw\|ADMIN_OVERRIDE\|1757568180000 |
| 历史迁移 | 卡片ID + 结果 + 原记录时间戳 | recvtLY8poT8zw\|会\|1757000000000 |

## 五、与message_id的关系

### message_id的用途
- message_id仍然保留在流水表中（如有），用于追溯群消息来源
- message_id是**可选项**，不是必填项
- 群指令场景下，message_id作为附加字段记录，便于回溯

### event_id与message_id的区别
| 维度 | event_id（新定稿） | message_id（原定稿） |
|------|-------------------|---------------------|
| 用途 | 流水表唯一键/幂等键 | 追溯群消息来源 |
| 必填性 | 必填 | 可选（仅群指令场景） |
| 生成方 | 系统自动生成 | 飞书平台生成 |
| 全场景通用 | ✅ 是 | ❌ 否（按钮/INIT/迁移无） |
| 业务语义 | ✅ 自带（卡/结果/时间） | ❌ 无（仅随机ID） |
