**操作**：
```

```

**系统回复**：
```
✅ 已记录错题并AI解析
📝 错题：复利计算公式我记成了(1+r)^n，但忘了要乘本金P
```

## 九、常见问题

### 9.1 群里发指令没反应

**排查步骤**：
1. 等 5 分钟（轮询周期）
2. 手动跑：`python learning_system.py --poll-once`
3. 检查计划任务：`Get-ScheduledTask -TaskName "V16_LearningPoll"`

### 9.2 闪卡复习没反应

**排查步骤**：
1. 确认发的是 `闪卡复习` 或 `开始闪卡复习`
2. 手动跑：`python learning_system.py --poll-once`

### 9.3 云端问答没推群

**排查步骤**：
1. 检查 GitHub Actions Run 是否 Success
2. 检查 Secrets：FEISHU_APP_ID、FEISHU_APP_SECRET 是否正确
3. 检查 CHAT_ID 是否正确

## 附录：V49.1 更新说明（2026-09-22）

### 修复的问题

1. **洞察指令无反应**：发"洞察：xxx"后机器人回复"未找到任务"
   - 原因：消息中包含"归档"一词被自然语态销项误判
   - 修复：洞察指令优先于自然语态销项，现在可以正常使用

2. **待办任务每5分钟重复推送**：每5分钟收到一次待办提醒
   - 原因：每次轮询都推送，无去重
   - 修复：每天只推送一次到期提醒

3. **学知识指令无反应**：发"学知识：xxx"后无回复
   - 原因：被误判为任务指令跳过
   - 修复：现在可以正常使用，DeepSeek V4 flash生成回答

### 使用建议

- 发洞察时，即使内容中包含"归档"、"完成"等词，也会被正确识别为洞察
- 到期提醒每天只推一次，不会重复打扰
- 学知识指令现在走DeepSeek V4 flash通道，约15秒返回结果
